# Meteo app

## 📄 Description
C'est une application qui te fournit la météo de la ville de ton choix. Elle affiche l'heure, la température, une description du temps, la vitesse du vent et le taux d'humidité.

Elle indique également l'emplacement de la ville sur une carte interactive via la bibliothèque *Leaflet*.

L'application utilise l'API *OpenCageData* pour convertir le nom de la ville en coordonnées GPS, puis transmet ces données à l'API *OpenWeatherMap*, qui récupère les informations météorologiques correspondantes.

Enfin, les données météo sont affichées, et la carte est centrée sur la ville avec un marqueur indiquant son emplacement.

Un indicateur de chargement est également présent pour signaler que les informations sont en cours de récupération.
